# kerilings-macros

Internal proc-macro crate for [kerilings](https://github.com/AABelkhiria/kerilings). At compile time it
embeds the exercises, their solutions and `info.toml` into the `kerilings` binary.

It is not meant to be used directly. To do the exercises, install kerilings:

```bash
cargo install kerilings
```

Forked from `rustlings-macros` in [Rustlings](https://github.com/rust-lang/rustlings). Licensed under MIT.
